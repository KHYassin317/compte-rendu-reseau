## Description

Infrastructure réseau complète simulée sous GNS3 :
- VLANs 10 & 20 avec routage inter-VLAN
- Pare-feu FortiGate 7.0.9 avec NAT et DMZ
- Serveur web Apache2 Ubuntu 24.04 (isett.tn)
- Adressage IPv4 et IPv6
